So everything emerges from this: • held still, upright → ≈ (0, 9.8): normal downward gravity. • tilted → in-plane part shrinks with tilt angle, points downhill (real strength, not arcade full-power). • flat on a table → in-plane part ≈ 0 → the fluid FLOATS (zero-g). • shaken → the vector swings transiently → slosh. • in free-fall → magnitude → 0 → weightless.
